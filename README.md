# Calculadora de IMC - Academia 🏋️‍♂️

Projeto desenvolvido durante as aulas de desenvolvimento web para praticar manipulação do DOM e eventos em JavaScript.

## 🚀 Funcionalidades
- Cálculo dinâmico do Índice de Massa Corporal (IMC) com base no peso e altura inseridos pelo utilizador.
- Validação automática do status corporal (Magreza, Normal, Sobrepeso e Obesidade).
- Atualização da interface em tempo real utilizando JavaScript (DOM).

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estrutura da página web e formulário.
- **CSS3**: Estilização e design responsivo.
- **JavaScript**: Lógica de cálculo, funções e manipulação do DOM.

## 💻 Como executar
1. Clona este repositório ou descarrega os ficheiros ZIP.
2. Abre a pasta no **VS Code**.
3. Usa a extensão **Live Server** para abrir o ficheiro `index.html` no teu navegador.
